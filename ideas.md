## Idea A: "Industrial Brutalism with Neon Accents"

**Design Movement:** Neo-Brutalism meets Industrial Tech

**Core Principles:**
1. Raw, unpolished surfaces contrasted with precision-engineered elements
2. Heavy typographic weight as primary visual structure
3. Grid-breaking asymmetry — content bleeds across columns deliberately
4. Monochromatic base punctuated by single electric accent

**Color Philosophy:** Near-black (#0D0D0D) base with raw concrete grey (#2A2A2A) surfaces. A single electric lime (#B4FF00) accent for CTAs and highlights — evoking energy circuits and power lines. Communicates industrial authority.

**Layout Paradigm:** Oversized text blocks that break the grid. Sections offset at 5-degree angles. Content columns of unequal width (70/30 split). Navigation as a vertical sidebar strip.

**Signature Elements:**
- Thick black border frames around cards (3–4px solid)
- Oversized section numbers as decorative anchors (01, 02, 03)
- Circuit-trace SVG lines connecting service blocks

**Interaction Philosophy:** Abrupt, confident transitions — no easing, just cuts. Hover states invert colors completely (black→lime). Scrolling triggers section-lock snapping.

**Animation:** Section entrance via horizontal slide-in from alternating sides. No fade — pure translate. Stagger delay of 80ms per element.

**Typography System:**
- Display: Space Grotesk Bold 900 — massive, condensed
- Body: IBM Plex Mono Regular — technical, precise
- Hierarchy: 96px / 48px / 24px / 14px

## Idea B: "Deep Ocean Tech — Dark Teal Depth"

**Design Movement:** Deep Tech Minimalism / Oceanic Depth

**Core Principles:**
1. Depth through layered dark backgrounds (not flatness)
2. Luminous data visualizations as decorative elements
3. Generous negative space with purposeful content islands
4. Premium B2B authority — restrained but powerful

**Color Philosophy:** Deep navy (#050E1F) base with teal-to-cyan gradient accents (#0EA5E9 → #06B6D4). Warm gold (#F59E0B) for key metrics and highlights. Communicates trust, technology, and sustainability.

**Layout Paradigm:** Full-bleed dark sections with floating card clusters. Hero uses split-screen: left is bold typography, right is an animated data visualization or generated image. Services arranged in a diagonal staircase pattern.

**Signature Elements:**
- Glowing border cards with subtle inner shadow
- Animated counter numbers for key stats (MW, clients, projects)
- Thin horizontal rule dividers with gradient fade

**Interaction Philosophy:** Smooth, deliberate — 400ms ease-in-out on all transitions. Cards lift on hover with glow intensification. Parallax on hero background.

**Animation:** Fade-up with slight scale (0.96→1.0) on scroll. Number counters animate when entering viewport. Hero text reveals word by word.

**Typography System:**
- Display: Syne ExtraBold — geometric, futuristic
- Body: DM Sans Regular — clean, readable
- Hierarchy: 80px / 44px / 22px / 16px

## Idea C: "Precision Engineering — Steel & Jade"

**Design Movement:** Swiss Precision meets East Asian Minimalism

**Core Principles:**
1. Structured grid with deliberate micro-spacing — every pixel intentional
2. Restrained palette inspired by Hong Kong's steel skyline and jade tradition
3. Information density without clutter — data tables as design elements
4. Horizontal scrolling panels for service showcases

**Color Philosophy:** Off-white (#F5F4F0) background with steel-grey (#374151) structure. Jade green (#059669) as the primary accent — referencing both sustainability and Hong Kong's cultural identity. Deep charcoal (#111827) for text.

**Layout Paradigm:** Swiss-grid 12-column structure. Hero is a full-width typographic statement with a right-aligned image inset. Services use a horizontal scrolling ticker-tape layout. Footer is a dense information grid.

**Signature Elements:**
- Thin 1px rule lines as section separators
- Jade-colored tag pills for service categories
- Monospaced stat blocks (energy output, uptime %, etc.)

**Interaction Philosophy:** Precise, no-nonsense. Hover reveals additional information in a slide-down panel. No decorative animations — only functional motion.

**Animation:** Subtle underline draw on nav hover. Content sections reveal via opacity (0→1) with 200ms delay. No parallax or dramatic effects.

**Typography System:**
- Display: Playfair Display Bold — editorial authority
- Body: Source Sans 3 Regular — technical clarity
- Hierarchy: 72px / 40px / 20px / 15px

## Selected Approach: **Idea B — "Deep Ocean Tech"**

Dark navy base with teal/cyan gradients, Syne + DM Sans typography, floating card clusters, animated stats, and luminous depth. This communicates enterprise-grade authority while evoking sustainability and cutting-edge technology — perfectly aligned with Infinity Bloom's positioning in renewable energy and data center development.
